# AIO PESTGUARD

Simulasi antarmuka web sistem deteksi hama AIGRA (padi, jagung, bawang). Next.js 14, React, TypeScript, Tailwind CSS. Tema hijau putih, ditujukan untuk petani.

```bash
npm install
npm run dev
```

Penjelasan sistem lengkap dan panduan integrasi backend: lihat `SYSTEM_OVERVIEW.md`.
